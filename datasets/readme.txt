Luciferase Expression (LE) values are reported as blank-subtracted, batch-normalized (across iterations) values. 

Please note that normalization was performed within each file/experiment. Thus, transfection values cannot be cross compared across files. 

Unique FALCON_IDs are assigned to each tested LNP composition. These are four digit codes that begin with an F (for FALCON datasets), or U (for Unguided Search datasets). The 1st digit identifies which experiment the formulation is from (0,1,2,3,4), and the last 3 digits identify the position of the formulation in the experimental dataset.

For example, F0100 denotes the 100th formulation from experiment 0.
